
# Shell, init files, variables and expansions

0-alias: Creates an alias named ls that runs rm -f *
1-hello_you: Prints hello followed by the current Linux username
2-path: Appends /action to the PATH environment variable
3-paths: Counts the number of non-empty directories in PATH
4-global_variables: Displays all environment variables using printenv
5-local_variables: Lists all local variables, environment variables, and shell functions
6-create_local_variable: Creates a local variable named BEST with the value School
7-create_global_variable: Creates an environment variable named BEST with the value School
8-true_knowledge: Adds 128 to the value of the TRUEKNOWLEDGE environment variable and prints the result
9-divide_and_rule: Divides POWER by DIVIDE and prints the result
10-love_exponent_breath: Calculates BREATH raised to the power of LOVE
11-binary_to_decimal: Converts a binary number stored in BINARY to decimal
12-combinations: Prints all two-letter combinations from aa to zz, excluding oo
13-print_float: Prints the NUM environment variable with two decimal places...
