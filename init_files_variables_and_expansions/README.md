# Shell, init files, variables and expansions

0-alias: Creates an alias named ls that runs rm -f *
1-hello_you: Prints hello followed by the current Linux username
2-path: Appends /action to the PATH environment variable
3-paths: Counts the number of non-empty directories in PATH
4-global_variables: Displays all environment variables using printenv
5-local_variables: Lists all local variables, environment variables, and shell functions......
